# Storier - A story design tool

This project aims to build a website using HTML and JavaScript. It mainly focus on a story writting and designing tool.

## Project structure

Keep everything clean and organized in the project folder. Add a `readme.md` and a design document recording all features and design standard.

The file structure is as follows:

- `assets/`: all project implementation required files. Create new folders here if new type of resources are used.
  - `srcs/`: all HTML, CSS, and JavaScript files. These files should also be grouped into subfolders as the project grows.
- `docs/`: designing and requirement documents. Documents should be updated with codes as the project add new features.

## Document Contents

- `features.md`: main functional feature designing document.
- `ui.md`: UI features and design guides.

These documents should be updated as the project grows.

## Code style requirements

The project uses JavaScript as major programming languages.

### Designning

- Use modern OOP, including classes and interfaces when needed.
- Use getter and setter for properties instead of `GetXXX()` when needed.

### Styles and Formats

- Code indentation is 4 spaces (for all codes including HTML and CSS).
- No need of semicolons at end of lines in JavaScript codes.
- Use modern code styles.
